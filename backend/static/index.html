Thông tin API TTS

Endpoint nhận POST và trả binary audio (PCM, WAV hoặc MP3).

Chưa lưu khóa API.

MP3 và WAV khác mono 24 kHz cần ffmpeg trên máy chủ.

JSON request & xác thực nâng cao +

Dùng {{text}}, {{voice}}, {{model}} để chèn nội dung. API trả JSON chứa URL âm thanh cần bổ sung adapter trong backend/tts.py.

02

Cấu hình trên ESP32

ESP32 và máy chủ cần cùng mạng. Không dùng localhost trên ESP32.

Sửa main/speaker_config.h
  1. Điền backend_url, device_id và device_token trong file cấu hình.
  2. Nếu thử HTTP trong LAN, đặt allow_http_for_development = true.
  3. Điền wifi_ssid, wifi_password, lưu file rồi build/nạp lại.

Loa hiện “Đang kết nối” sau khi firmware hỏi backend. Trạng thái không được mô phỏng.
